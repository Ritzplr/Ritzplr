## Featured project

**[opswatch](https://github.com/Ritzplr/opswatch)** is a dependency-free health checker for small teams. It watches HTTP endpoints, TLS certificate expiry, TCP ports, disk usage and backup freshness, and alerts only when something changes. Written in Python with a full test suite and CI on Linux and Windows.
